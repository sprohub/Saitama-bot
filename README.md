# ⚡ SOBRE SAITAMA BOT

**Saitama Bot** es un bot de WhatsApp multipropósito inspirado en la fuerza y poder de **Saitama** (One Punch Man). Integra sistemas de entretenimiento, administración de grupos, descargas multimedia, economía RPG y herramientas avanzadas para usuarios y administradores.

> Diseñado para brindar una experiencia fluida, rápida y completa dentro de WhatsApp.

# 🚀 INSTALACIÓN

### Clonar repositorio

```bash
git clone https://github.com/sproh/SaitamaBot.git
```

### Entrar a la carpeta

```bash
cd SaitamaBot
```

### Instalar dependencias

```bash
npm install
```

### Iniciar el bot

```bash
npm start
```
